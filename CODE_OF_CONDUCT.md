# Code of Conduct

This project adheres to the
[Qiskit Code of Conduct](https://github.com/Qiskit/qiskit/blob/main/CODE_OF_CONDUCT.md).
All contributors, maintainers, and users participating in project spaces are
expected to follow those community standards.

## Expected Behavior

- Be respectful, inclusive, and constructive.
- Give and receive technical feedback in good faith.
- Focus discussions on reproducible evidence, code quality, and scientific
  integrity.
- Respect differences in experience level, background, language, and viewpoint.

## Unacceptable Behavior

- Harassment, intimidation, discrimination, or personal attacks.
- Public or private abuse, including sustained disruption of project work.
- Publishing private information without explicit permission.
- Misrepresenting results, authorship, or project affiliation.

## Enforcement

Project maintainers may moderate, edit, or remove issues, discussions, comments,
or pull requests that violate this code of conduct. Repeated or severe violations
may result in temporary or permanent exclusion from project spaces.

To report a concern, contact the maintainers through the repository issue
tracker or through the contact information listed on the project repository.
Reports will be handled with care and, when possible, confidentiality.
